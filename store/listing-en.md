# Store Listing (English)

## Name
YouTube JP Dub — Instant Japanese Dubbing for Any Video

## Short description (≤132 chars)
Listen to YouTube in Japanese. Auto-paced text-to-speech dubbing that fits each caption's timing. No AI fees, no signup, 100% free.

## Detailed description

Turns any captioned YouTube video into a Japanese-dubbed experience, in real time.

■ Highlights
- Auto-pacing engine — speech rate adapts to each caption's time window and catches up when it falls behind, so narration never drifts away from the video
- Two playback modes — "Ducking" (lowers original audio, interpreter-style) and "Auto-pause" (pauses per sentence, great for study)
- Premium voices — automatically prefers Microsoft Edge Natural voices; uses your OS Japanese voices on Chrome
- Japanese subtitle overlay
- No account, no API key, no external AI service. Nothing is sent anywhere

■ How to use
1. Open a YouTube video that has captions
2. Enable dubbing from the toolbar popup or the on-player panel
3. Adjust voice, speed and mode to taste

■ How it works / limits
Uses YouTube's own translated captions as the source, so videos without any captions are not supported. Translation quality follows YouTube auto-translation.

■ Privacy
Collects no browsing data, audio, or personal information. Settings are stored only in your browser's sync storage.
